title: "Make airtime purchases via parent account (v2)"
---

<Warning>
Always requery the transaction using [Fetch a single transaction on the parent account](/nomba-api-reference/requery/fetch-a-single-transaction-on-the-parent-account) to confirm its final status before issuing a refund. Only issue a refund if `data.status` is `REFUND`.
</Warning>

<Note>
The `code` field in the response reflects the HTTP status code of the response. For example, `200` means the request completed successfully, and `201` means it was accepted and is still being processed.
</Note>
