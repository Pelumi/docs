<Warning>
Always requery the transaction using [Fetch a single transaction on the parent account](/nomba-api-reference/requery/fetch-a-single-transaction-on-the-parent-account) to confirm its final status before issuing a refund. Only refund if `data.status` is `REFUND`.
</Warning>


<Note>
Send the plan's `productId` from [Fetch cable TV plans (v2)](/nomba-api-reference/bills/fetch-cable-tv-plans-v2) to choose the plan. When `productId` is sent, that plan is bought at its price and `amount` is ignored. Without `productId` the plan is chosen by `amount`; if more than one plan costs that amount the request is rejected and nothing is charged. A `productId` is unique only within its `cableTvType`, so send it with the same `cableTvType` the plans were fetched for.
</Note>
