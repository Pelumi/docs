<Info>
  **In a nutshell:** after a customer's first successful card payment, save the card's `tokenKey`. Use it to charge the customer again without asking for their card details. If their bank asks for an OTP, collect it and submit it to complete the charge.
</Info>

## 1. Charge the first transaction

Create a checkout order with `tokenizeCard: true` and let the customer pay with their card. See [Tokenize Card](/docs/products/accept-payment/create-checkout-order#tokenize-card).

```json
"tokenizeCard": true
```

<Tip>
  Only include `tokenizeCard: true` if you intend to charge the customer's card again later.
</Tip>

## 2. Get the token

When the payment succeeds, Nomba sends a `payment_success` [webhook](/docs/api-basics/webhook). The card's token is in `data.tokenizedCardData`:

```json
{
  "event_type": "payment_success",
  "data": {
    "tokenizedCardData": {
      "tokenKey": "7628788443",
      "cardType": "Visa",
      "cardPan": "4***45**** ****111*"
    },
    "order": {
      "orderReference": "90e81e8a-bc14-4ebf-89c0-57da752cca58",
      "customerEmail": "abcde@gmail.com"
    }
  }
}
```

| Field | Description |
| --- | --- |
| `tokenKey` | The token to charge the card with |
| `cardType` | The card scheme, for example `Visa` |
| `cardPan` | The masked card number |

You can also find a customer's tokens at any time with [List Tokenized Cards](/nomba-api-reference/online-checkout/list-tokenized-cards), using the customer's email as `customerEmail`.

## 3. Store the token

Save the `tokenKey` together with the customer's email, so you know which token to charge for each customer.

## 4. Charge the token

When the next payment is due, send the `tokenKey` and the order details to [Charge a Tokenized Card](/docs/products/accept-payment/charge-tokenized-card).

- If `otpRequired` is `false`, the charge is complete. Go to step 6.
- If `otpRequired` is `true`, the customer's bank requires an OTP. The charge stays pending and the response includes a `transactionId`. Go to step 5.

## 5. Submit the OTP

The customer's bank sends an OTP to the phone number or email registered with the card. Collect it from the customer and send it with the `orderReference` and `transactionId` to [Submit Tokenized Card OTP](/docs/products/accept-payment/submit-tokenized-card-otp).

<Note>
  A charge whose OTP is not submitted within about 15 minutes is marked as failed.
</Note>

## 6. Verify the transaction

Confirm the final status before giving value to your customer. Nomba sends a webhook for instant notification, and you should verify the transaction via the [Verify Transactions](/docs/products/accept-payment/verify-transactions) endpoint.
