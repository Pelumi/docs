# `GET /v1/transactions/virtual`

Fetch transactions on a virtual account. Pass the `virtual_account` query parameter with the account number. You can also filter by `dateFrom` and `dateTo`.

<Note>
  Transaction APIs are paginated. We recommend reviewing the [pagination guide](/docs/api-basics/pagination) to understand how to work with paginated endpoints.
</Note>

#### Query parameters

<ParamField query="virtual_account" type="string" required>
  The virtual account number
</ParamField>

<ParamField query="dateFrom" type="string">
  Start date for filtering transactions
</ParamField>

<ParamField query="dateTo" type="string">
  End date for filtering transactions
</ParamField>

#### Response body

<ResponseField name="code" type="string" required>
  Response code
</ResponseField>

<ResponseField name="description" type="string" required>
  Response description
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="object" defaultOpen="true">
    <ResponseField name="results" type="object[]">
      List of virtual account transactions
    </ResponseField>
    <ResponseField name="cursor" type="string">
      Pagination cursor for next page
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash Request
curl --request GET \
  --url 'https://api.nomba.com/v1/transactions/virtual?virtual_account=8578228675&dateFrom=2025-06-24&dateTo=2025-06-25' \
  --header 'accountId: <accountId>' \
  --header 'Authorization: Bearer <token>'
```
</RequestExample>
