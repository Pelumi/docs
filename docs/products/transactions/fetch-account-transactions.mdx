# `GET /v1/transactions/accounts`

Fetch account transactions within a specific timeframe. You can pass query params to specify a timeframe using `dateFrom` and `dateTo`. You can also set a `limit` as it's a paginated endpoint.

<Note>
  Transaction APIs are paginated. We recommend reviewing the [pagination guide](/docs/api-basics/pagination) to understand how to work with paginated endpoints.
</Note>

#### Query parameters

<ParamField query="limit" type="integer">
  Number of results to return per page
</ParamField>

<ParamField query="dateFrom" type="string">
  Start date for filtering transactions (ISO 8601 format)
</ParamField>

<ParamField query="dateTo" type="string">
  End date for filtering transactions (ISO 8601 format)
</ParamField>

#### Response body

<ResponseField name="code" type="string" required>
  Response code
</ResponseField>

<ResponseField name="description" type="string" required>
  Response description
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="object" defaultOpen="true">
    <ResponseField name="results" type="object[]">
      List of transactions
    </ResponseField>
    <ResponseField name="cursor" type="string">
      Pagination cursor for next page
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash Request
curl --request GET \
  --url 'https://api.nomba.com/v1/transactions/accounts?limit=10&dateFrom=2023-01-01T00:00:00&dateTo=2025-01-01T00:00:00' \
  --header 'Authorization: Bearer <token>' \
  --header 'accountId: <accountId>'
```
</RequestExample>
