# `GET /v1/transactions/bank`

Fetch debit or credit transactions associated with an account.

<Note>
  Transaction APIs are paginated. We recommend reviewing the [pagination guide](/docs/api-basics/pagination) to understand how to work with paginated endpoints.
</Note>

#### Query parameters

<ParamField query="limit" type="integer">
  Number of results to return per page
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor for scrolling to the next page. Only use when returned by a previous request.
</ParamField>

<ParamField query="dateFrom" type="string">
  Start date for filtering transactions (UTC). Example: `2023-01-01T00:00:00`
</ParamField>

<ParamField query="dateTo" type="string">
  End date for filtering transactions (UTC). Example: `2024-09-30T23:59:59`
</ParamField>

#### Response body

<ResponseField name="code" type="string" required>
  Response code
</ResponseField>

<ResponseField name="description" type="string" required>
  Response description
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="object" defaultOpen="true">
    <ResponseField name="results" type="object[]">
      List of bank transactions
    </ResponseField>
    <ResponseField name="cursor" type="string">
      Pagination cursor for next page
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash Request
curl --request GET \
  --url https://api.nomba.com/v1/transactions/bank \
  --header 'Authorization: Bearer <token>' \
  --header 'accountId: <accountId>'
```
</RequestExample>
