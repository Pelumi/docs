# `GET /v1/bill/data-plan/{telco}`

<Warning>
  The plans, amounts, and `productId`s in the example response are **illustrative only** — they do not represent real, current plans. This catalog can change at any time. Never hardcode plan data from this example: always call this endpoint live and use the `productId` it returns in your purchase request.
</Warning>

#### Path parameters

<ParamField path="telco" type="string" required>
  Telco i.e. network provider for the data plan to be purchased. Typically mtn,
  airtel, glo or 9mobile
</ParamField>

#### Response body

<ResponseField name="code" type="string" required>
  Response code
</ResponseField>

<ResponseField name="description" type="string" required>
  Response description
</ResponseField>

<ResponseField name="message" type="string" required>
  Response message
</ResponseField>

<ResponseField name="status" type="boolean" required>
  Request status
</ResponseField>

<ResponseField name="data" type="object[]">
  List of available data plans for the telco supplied
  <Expandable title="object" defaultOpen="true">
    <ResponseField name="amount" type="integer" required>
      The corresponding amount for this plan
    </ResponseField>
    <ResponseField name="plan" type="string" required>
      Plan name
    </ResponseField>
    <ResponseField name="productId" type="string" required>
      The unique identifier for this data plan. Pass this value as `productId` in the [Buy Data Bundle](/docs/products/airtime-and-data/buy-data-bundle) request to purchase this exact bundle.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash Request
curl --location 'https://api.nomba.com/v1/bill/data-plan/mtn' \
--header 'accountId: <accountId>' \
--header 'Authorization: Bearer <token>'
```
</RequestExample>
