# `GET /v2/bill/electricity/lookup`

Use this endpoint to confirm a customer's details before you vend electricity. It returns the customer's name and address as held by the electricity provider.

<Warning>
`GET /v1/bill/electricity/lookup` is deprecated and will be removed in a future release. It returns only the customer's name as a string. Move to `GET /v2/bill/electricity/lookup`, where `data` is an object containing `name` and `address`.
</Warning>

#### Query parameters

<ParamField query="disco" type="string" required>
  The code name of the electricity provider as gotten when the list of discos is fetched e.g. phed
</ParamField>

<ParamField query="customerId" type="string" required>
  The unique identifier of the customer on the provider's platform, such as the meter number
</ParamField>

#### Response body

<ResponseField name="code" type="string" required>
  Response code
</ResponseField>

<ResponseField name="description" type="string" required>
  Response description
</ResponseField>

<ResponseField name="data" type="object" required>
  The customer's details
  <Expandable title="object" defaultOpen="true">
    <ResponseField name="name" type="string" required>
      The name of the customer
    </ResponseField>

    <ResponseField name="address" type="string" required>
      The address of the customer. Returns `unknown` when the provider does not supply an address.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="message" type="string" required>
    Response message
</ResponseField>

<RequestExample>
```bash Request
curl --location 'https://api.nomba.com/v2/bill/electricity/lookup?disco=phed&customerId=12347899' \
--header 'accountId: <accountId>' \
--header 'Authorization: <token>'
```
</RequestExample>

<ResponseExample>
```json Success response
{
    "code": "00",
    "description": "SUCCESS",
    "data": {
        "name": "John Doe",
        "address": "12 Adeola Odeku Street, Victoria Island, Lagos"
    }
}
```
</ResponseExample>
