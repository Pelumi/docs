## `GET /v2/bill/cableTvProduct?cableTvType=dstv`

<Note>
`GET /v1/bill/cableTvProduct` is deprecated. It returns the same plans without `productId` and keeps working for now. Use the v2 endpoint so you can subscribe by `productId`.
</Note>

Available Cable TV type:  
1. dstv  
2. gotv  
3. startimes
4. ShowMax

#### Response body

<ResponseField name="code" type="string" required>
  Response code
</ResponseField>

<ResponseField name="description" type="string" required>
  Response description
</ResponseField>

<ResponseField name="message" type="string" required>
  Response message
</ResponseField>

<ResponseField name="data" type="object[]">
  List of available subscription plans
  <Expandable title="object" defaultOpen="true">
    <ResponseField name="productId" type="string" required>
      Identifier of the plan. Send it as `productId` when subscribing to buy this exact plan
    </ResponseField>
    <ResponseField name="subScriptionType" type="string" required>
      The subscription plan type (e.g., DSTV_STARTER_E36, DSTV_PREMIUM)
    </ResponseField>
    <ResponseField name="amount" type="number" required>
      The amount for the subscription plan
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash Request
curl --location 'https://api.nomba.com/v2/bill/cableTvProduct?cableTvType=dstv' \
--header 'Authorization: Bearer <token>' \
--header 'accountId: <accountId>'
```
</RequestExample>
